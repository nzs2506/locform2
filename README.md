# LOCform 2.0

LOCform 2.0 converts CRM/promo source text into three HTML variants:

- Web
- Mobile
- Redesign

## Local Run

```bash
npm start
```

Then open:

```text
http://127.0.0.1:4173/
```

## GitHub Pages

This repository includes a GitHub Pages workflow that publishes the `public/` folder.

After pushing to GitHub:

1. Open the repository settings.
2. Go to `Pages`.
3. Set source to `GitHub Actions`.
4. Open the deployed Pages URL after the workflow finishes.
