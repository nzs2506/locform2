Как подготовить Word-файл

1. Ключи

Для заголовка пишите ключ с окончанием .topic, для основного текста — такой же ключ без .topic.

COM ENG
message.service.6045.topic
Day 1 is live!

message.service.6045
Main notification text...

2. Неразрывные пробелы

В начале языкового блока можно перечислить фразы, где пробелы должны стать &nbsp;.

Неразрывные пробелы: Free Spins, Spin Master, Big Bass Football Bonanza

Если такая фраза есть в topic, в поле Topic появится обычная версия и отдельная версия для redesign с &nbsp;.

3. Кнопки и версии сайта

redesign, new site, new version — ссылка для Redesign. Old version, old site — ссылка для Web и Mobile.

Самый понятный формат для скрипта — сначала цвет кнопки, потом фраза в кнопке, потом версия сайта, потом отдельной строкой ссылка. Скобки вокруг ссылки можно ставить: скрипт уберёт внешние ( и ).

Если внутри ссылки случайно стоит пробел перед ?, &, = или после них, скрипт уберёт его при сборке кнопки.

Зеленая кнопка
Узнать больше
redesign
(/promotions/promotion/1578?utm_medium=an...)

Old version
Узнать больше
(https://go2m.biz/...url_web=en/promotions/promotion/1578...)

Если для одной и той же кнопки рядом нужны и Redesign, и Old version, название кнопки можно не повторять: следующая версия унаследует последнюю фразу кнопки.

Зеленая кнопка
Узнать больше
redesign
(/promotions/promotion/1578?utm_medium=an...)

Old version
(https://go2m.biz/...url_web=en/promotions/promotion/1578...)

Если кнопок несколько, лучше писать их подряд одним блоком, без обычного текста между ними.

Зеленая кнопка: Получить бонус (/account/deposit)
Белая кнопка: Узнать больше (/promotions/promotion/411)

4. Списки

Для маркированного списка пишите каждый пункт отдельной строкой и начинайте его с дефиса. Заголовок списка оставляйте отдельной строкой над пунктами. Скрипт соберёт это в обычный <ul> и <li>.

В Web списки выводятся без тегов <ul> и <ol>: маркированные пункты становятся строками с &bull;, нумерованные — строками с цифрами. В Mobile и Redesign остаются настоящие списки.

Если строка перед списком заканчивается двоеточием, список будет прижат к ней без большого пустого отступа. Самый понятный формат: сначала вводная строка с :, затем пункты отдельными строками.

Чтобы принять участие, выполните условия:
- съешьте банан
- съешьте пиццу
- выпейте кофе

Для рабочих условий формат такой же:

Условия:
- Максимальная сумма ставки 500 000 UZS.
- Один счёт = одна ставка.
- Учитываются только одиночные предматчевые ставки.

Нумерованный список тоже лучше писать по одному пункту на строку.

1. Нажмите кнопку «Участвовать».
2. Сделайте ставку.
3. Получите бонус.

5. Цвета кнопок

Зелёную кнопку можно писать как Зеленая кнопка, Кнопка зеленая, Green button или Button green. Белую — Белая кнопка, Кнопка белая, White button или Button white.

6. Интервалы и 18+

Для пустой строки пишите отдельной строкой Междустрочный интервал или Межстрочный интервал. После финальной строки 18+ | ... ничего не добавляйте: всё ниже будет отрезано.

7. Ссылки внутри текста

Если фраза в Word уже содержит ссылку, скрипт сохранит её как подчёркнутую курсивную ссылку. Лучше вешать ссылку только на нужную фразу, не на весь абзац.

Картинки для кнопок Redesign

Если версия, язык, текст кнопки и цвет совпадают со строкой в таблице, в Redesign вместо текстовой кнопки будет вставлена картинка. В PC строки сгруппированы по смыслу кнопки: для нового блока переводов укажите одинаковое название в колонке Группа. Строки без группы уйдут в серый блок Без группы. Сохранить локально оставляет изменения только в этом браузере, Сохранить в общий добавляет варианты в общий список для всех пользователей через Cloudflare.
